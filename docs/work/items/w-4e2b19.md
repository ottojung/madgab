# The `approximate_output_is_locked` re-lock comment contradicts itself and
# understates the churn it describes

## Defect

`tests/corpus_integration.rs`, in the comment above the
`approximate_output_is_locked` fixture, re-locked by
[w-9c6f2b](w-9c6f2b.md):

> What actually changed, so a reviewer does not have to re-derive it:
> **five of the ten phrases are different.**  The two leading phrases
> **and the scores of the retained ones are unchanged**, but ...

The scores of the retained phrases are not unchanged. The same fixture,
same diff, measured:

| retained phrase | before | after |
|---|---|---|
| `isle a view` | 0.938335 | 0.936034 |
| `aisle a view` | 0.937604 | 0.935302 |
| `isle of new` | 0.930994 | 0.922661 |
| `aisle of new` | 0.930262 | 0.921929 |
| `yeah ill view` | 0.929948 | 0.920124 |

Every one falls, by 0.0023 to 0.0087. The comment's own preceding
paragraph says the opposite and says it correctly — "every score falls by
`SIMILARITY * cost / 12`, which is 0.0023 to 0.0024 across this list" — so
the fixture contains two sentences that cannot both be true, and the
contradicting one is the one written to be read first.

## Why it is worth fixing rather than ignoring

This comment is the artifact a later reviewer consults to decide whether a
further change to the objective axes is acceptable. It is the difference
between "two phrases changed and the rest held their scores" — which reads
as a stable lock — and "five phrases changed and all ten scores moved" —
which reads as a lock that is re-baselining on every axis change. The
first understates the churn by an order of magnitude and is the wrong
thing to conclude from. The five-of-ten figure in the same sentence is
correct, which makes the false clause more dangerous, not less: it reads
as a checked detail.

The change itself is fine and the churn is disclosed honestly in
[w-9c6f2b](w-9c6f2b.md), whose before/after table is correct. This is a
defect in the code comment only, not in the fixture, the lock value, or
the front's reasoning.

## Fix

Correct the clause to the measured facts, and drop the `0.0023 to 0.0024`
range in the preceding paragraph to the true per-entry spread of
`0.0023 to 0.0087`, or state it as a per-axis bound
(`SIMILARITY * cost / 12`) without asserting a range that the fixture
contradicts. One-line change, no behaviour, no re-lock.
