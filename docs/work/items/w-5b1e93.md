# The blocker is emission order: make the traversal's slot width and suffix bound budget-derived instead of uniform

## Goal

Make the lexical traversal reach a wording that is **deep in one slot** at
the same worst-case cost as a shallow one, so the second canonical clue is
emitted into the approximate pool. General mechanism, general benefit; no
phrase-specific case.

## Why this item exists

Six fronts have now been refuted by measurement, and the sixth of them named
this one. [w-7e1a04](w-7e1a04.md) closed as a priced negative on 2026-09-27:
in a controlled population of 3,717 faithful resegmentations the two axes its
hypothesis named *reward* being finer (positive slope against clue word count
on 10/10 informative targets), and a perfect repair of the named defect is
worth `0.018750` against a gap of `0.094352`. Its verdict, in its own words:

> the blocker is emission order — the clue is 0 of 18,936 pool members and
> 0 of 23,296 dumped candidates, so it is not in the pool to be reweighted.

[w-b3e91a](w-b3e91a.md) priced the same thing from the other end: at the
**full** per-slot width of 160 the traversal emits 2,036,664 wordings of the
canonical segmentation's own structure, reaches index 159, and still never
emits the canonical tuple. A factor of **124** in the cheapest reallocation
and **1,309** in the segmentation's 2,666,496,000-wording product. It is an
*order* limit.

## The two uniformities that cause it

Both are in `src/lib.rs`, in the per-segmentation lexical phase, and both are
general properties of the current implementation rather than tuning choices.

1. **Every slot opens at one width.** [`LEXICAL_BRANCH_STAGE_0`] = 10 is the
   starting width, and the canonical alignment's per-slot ranks over the
   160-wide shortlist are **3 / 2 / 10 / 99 / 11** ([w-7b41d2](w-7b41d2.md)).
   Four slots are inside a width of 11; exactly one is not. So the clue needs
   *one slot to be much deeper than the others* and the uniform width is the
   thing that forbids it. The width is already justified by a real argument —
   a best-first walk over a `d`-slot product spends `1 + w + w^2 + ... +
   w^(d-1)` pops before its first wording, so `w` is only a budget if that
   series fits inside `LEXICAL_HEAP_POP_LIMIT` — but that argument is
   *worst-case over all slots being deep at once*, which is the same
   simultaneity assumption the item above names.
2. **The suffix bound is a separable sum of independent per-slot extrema.**
   `suf_min_cost`, `suf_min_reused`, `suf_max_fam`, `suf_min_closed`,
   `suf_min_syl`/`suf_max_syl` are each a running sum of that slot's own best
   or worst value, and the bound composes them as if one slot could be
   simultaneously cheapest, least-reusing, most familiar, least closed-class
   and syllable-extremal. It is admissible and it is loose, and a loose bound
   is exactly what makes the traversal walk 2,036,664 wordings that cannot
   beat the clue before reaching it.

The affordability model already in `src/lib.rs` (`slot_is_affordable`) shows
the intended shape of the fix and is the precedent to follow:
`committed + later_minima + cost_{k,i} <= total_budget` admits a deep
candidate in one slot at no extra worst-case cost, because the other slots
pay their own minima. The same reasoning applied to *width* and to the
*joint* suffix state is this item's work.

## Suggested shape of the work

Deliver the measurement first, then the change:

1. **Quantify the looseness.** On real targets, compare the traversal's bound
   against the best *achievable* completion score at each prefix depth, and
   count how many wordings of a given segmentation precede a wording that is
   deep in a single slot, under (a) the current separable bound and (b) a
   jointly-admissible Pareto bound over the per-slot tables (state =
   committed cost, syllables, closed count, reuse count). This can be
   computed offline on a `scratch/` branch without changing the search, and
   it prices the fix before it is written.
2. **Make the opening width per-slot and derived**, in the spirit of
   `slot_is_affordable`: slot `k` admits as many of its candidates as
   `committed_min + later_minima + cost_{k,i} <= total_budget` allows, capped
   by what the pop-limit argument affords. Record what the cap still bounds.
3. **Tighten the suffix bound** from separable extrema to a bounded
   deterministic Pareto relaxation, keeping it admissible — an inadmissible
   bound silently changes which wordings are emitted and is a correctness
   bug, not a tuning choice. Assert admissibility executably.
4. Keep determinism: emission order and the beam's `seen` set are already
   deterministic ([w-3d6c81](w-3d6c81.md)), and `--test approx_determinism`
   must stay green.

  pre-existing rank-50 cutoff before believing a number from it. Current
  reference values, release, `--top 50`, defaults, on the public
  `Generator::generate_pool`: case 2 pool **18,936** / rank-50 cutoff
  **0.915121574454**; case 1 pool **18,270** / **0.918796440893**
  ([w-474813](w-474813.md)).

  every number.

  test and no temporary `#[cfg(test)]` counters may reach the accumulation
  branch. Probe work belongs on a separate `scratch/` branch in its own
  worktree.
* `cargo` reuses stale binaries across `git bisect`; force a rebuild or the
  "first bad commit" will be a docs commit.
* **Never use `git checkout <file>` for a mutation red-check.** That cost this
  repository a whole in-flight change twice ([w-7e1a04](w-7e1a04.md)).
  Red-checks go in a scratch worktree on a scratch branch.
* Commit **and push** implementation work before spending further turns
  measuring, finish on a named branch, and check
  `git branch --contains <head>` before treating the branch as safe. A
  finished agent on a detached HEAD is unrecoverable from a later pass.
