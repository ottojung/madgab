# Make enumeration depth cost additively: stratified frontier order

## Goal

The per-segmentation lexical enumeration in `src/lib.rs` is a best-first
product search over prefixes. Its frontier grows by the per-slot fan-out at
every level, so a combination that is deep in one slot sits behind every
better-bound prefix at each level above it, and depth in one slot costs
*multiplicatively* in the levels. This front changes the **order** so that
depth in one slot costs *additively*: visit the index tuples over the per-slot
candidate lists by max-index-first stratification (a diagonal / per-slot index
round-robin), spending the existing emission and pop budget on that order.
