# Add a content-word prior to approximate clue scoring

## Goal

Approximate mode should not propose clues built out of English closed-class
words. It should prefer content words, so that the proposals it returns
read like something a person would actually say out loud as a puzzle
answer.

## Context

Continuation of [w-4b1e07](w-4b1e07.md). The current top proposals for
real targets are function-word salads:

- `It's just a stupid game` -> `it justice two bad aim`,
  `each thus tess to pad aim`
- `recognize speech` -> `wreck a nice each`
- `a whole lot of trouble` -> `so la cut are -able`

Both canonical answers are content-heavy by contrast: `hits justice dupe
hid came` has no closed-class item, `wreck a nice beach` has only the
article. Under a closed-class penalty the same prior that improves
general output quality also happens to lift both canonical cases, which is
why this is worth measuring properly rather than guessing at weights.

Antonina agent `a1b2c301` reached the same conclusion independently:
"closing that needs a *lexical quality* model (closed-class word class,
English bigram plausibility), not a better search".

The corpus (`open-english-pronouncing-dictionary` 0.1) already carries
`rarity` for every entry, so a small, standard closed-class word list is
the only new data needed, and no new dependency.

## Completion criteria

- A general closed-class / content-word signal participates in approximate
  clue scoring, derived from a linguistically standard closed-class list,
  not from any observed candidate set.
- The weight is chosen by measuring proposal quality over a spread of
  targets, and the measurement is recorded in this item. It must not be
  tuned against `recognize speech` or `It's just a stupid game`.
- A regression test expresses the property at an appropriate boundary:
  for a spread of targets, the proposals are predominantly content words
  and no single boundary structure occupies most of the proposal list.
- `cargo test --release` is green and search wall clock does not regress.
- If the evidence shows the axis does not improve aggregate quality, the
  item is closed as `superseded` with the measurements, not left half
  applied.
