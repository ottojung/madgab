# Price remaining shape 1: a stage-4 admission cut that is not a function of any single scalar per-candidate property

## Goal

Price, from cited numbers and from the code's own arithmetic, the one coordinate that
[../OBSTRUCTION-MAP.md](../OBSTRUCTION-MAP.md) §3 still lists as **unpriced and genuinely available**:
a per-slot admission cut at stage 4 keyed on a **structural / coverage / rank-band** property of the
span's own candidate set, rather than on any single scalar per-candidate property such as cost,
`contribution` ratio, or a cheap-end cost floor.

The deliverable is a written answer to a narrow question, plus either a ready-to-implement design
or a priced negative. This is a **pricing front, not an implementation front.**

## Why

`OBSTRUCTION-MAP.md` §3 closes thirteen coordinates and leaves three unpriced shapes. Shape 1 is the
one both `w-5e2d41` fronts named independently (front A's A6, front B's §4.1), and it is now free:
`w-1c7d40` (per-slot order), `w-5d9c04` (per-slot admitted set by cost median-straddle) and
`w-5e2d41` (floor / coverage retention) are all `done` and their branches are integrated. Nothing
owns this surface. If it is feasible, it is the only remaining search-side coordinate that can move
canonical **case-2 reach**, because the map's §3 "not unpriced" list rules out every other
candidate.

## The question to answer

For a span of `n` slots with per-slot rank cap `cap`, the map records the decisive constraints:

* a candidate at slot rank `r` is unreachable unless `r < cap` — `10 / 7 / 5` at depth `<= 4 / 5 / 6`;
* the canonical case-2 clue needs a slot rank of `119`, so it is out at depth 5 by 17x;
* a 16-draw sample of a `4.266e11` grid covers each **slot**, never the **tuple**;
* therefore any viable property must be a statement about the **first `cap` ranks of each slot**,
  not about global draw coverage.

So: **is there a structural, coverage or rank-band property of the first `cap` ranks of each slot
that (a) is computable inside the existing traversal without changing the budget, (b) does not
re-specify a closed row, and (c) would admit the needed rank-119 class at all under a cap of 7 at
depth 5?** Answer it with the arithmetic, and if (c) fails, say so and price the negative.
