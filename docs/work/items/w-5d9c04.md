# Admit a per-slot *set* that straddles the slot's median cost instead of the first `cap` indices

## Goal

The stage-4 opening-width test is `index < cap` on one flat per-slot list, so the traversal keeps the
first `cap` candidates of whatever order it is given and throws the rest away. Replace that
**prefix cut** with a **set cut** that admits the `cap` candidates whose cost straddles the slot's
median, at the same spend and with no extra pops, and establish whether that makes the canonical
case-2 tuple representable.

## Why this is the cheapest remaining coordinate

[../REPORT-1c7d40.md](../REPORT-1c7d40.md) §7.2 prices three successors after its own priced
negative. Coordinate 1 is this one. The two measurements that motivate it, re-derivable from
`REPORT-1c7d40` §4 on integrated HEAD:

* the canonical's needed per-slot candidates sit at cost percentile **0.43 / 0.38** while the
  `cap`-th candidate of the same slot is already at **0.50 / 0.43** — the needed words are *cheaper*
  than their own slot's median, so a median-straddling set is exactly the rule that would include
  them where a prefix does not;
* the opening width is a **0.0114**-wide band of a key whose whole-list width is **0.0338**, so the
  cut passes through a smooth cost function rather than separating a cluster from noise.

Spend is identical: still `cap` candidates per slot, still `LEXICAL_HEAP_POP_LIMIT` pops, no new
budget. This is a *set* rule, so it does not need — and must not claim — the descending-bound
property that `REPORT-1c7d40` priced as load-bearing (its candidate D, `contribution`-ascending,
halved the pool and dropped the green case entirely).
